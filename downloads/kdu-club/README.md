동아리 이름·분야·소개로 개설 신청합니다. 최소 인원·특정 캠퍼스·공식 서류 확인·정해진 파일명 조건이 없습니다. 상세 정보·월별 계획·첨부는 선택입니다. 공식 파일 다운로드와 담당자 연락처는 제거했습니다.

ZIP에는 README·검증 문서·qa·스크린샷·tests·.gitignore가 없습니다. 실행 파일·DB·instance·static·templates와 아이콘 라이선스만 유지합니다. 개발용 검증은 [GitHub 소스](../../projects/kdu-club)에 보관합니다.
