# D01–D12 수정·검증 기록

## 기존 코드에서 보완한 내용

- 공유 헤더·카드·필드·상태 배지와 데스크톱 CSS/JS로 화면을 교체했습니다.
- 활동 캠퍼스·요일·회비·가입 조건·활동 계획·반려 사유를 DB에 추가했습니다.
- 모집 회차를 별도 테이블로 분리해 전체 부원과 이번 모집 승인 수를 구분했습니다. 기간, 조기마감, 신규 정원, 새 모집 전 미처리 신청을 검증합니다.
- 교수 계정을 개설 심사 전용으로 제한하고 신청자·개설자·알림 소유자의 권한을 서버에서 검사합니다.
- 필수 반려 사유, 개설 수정 후 재신청, 이전 사유 표시, 신청 취소와 결과 팝업을 추가했습니다.
- 알림 전체/안읽음과 읽음 처리, 결과 이동을 구현했습니다. 상태가 pending에서 바뀐 요청에만 알림을 기록합니다.
- 공지 작성·수정과 10MiB/최대 3개 첨부를 구현했습니다. 업로드를 분리하여 실패 후 제목·본문·기존 첨부를 유지합니다.
- 일정 등록·수정·삭제 확인과 취소, 시간 검증 및 날짜순 목록을 구현했습니다.
- 공개·익명 및 비밀 Q&A를 구현하고 비밀 질문을 서버 조회 단계에서 제한했습니다.
- 검색은 파라미터 바인딩을 사용합니다. 비밀번호 해시·CSRF를 유지하고 기존 DB 보완 작업을 반복 가능하게 만들었습니다.

## 로그인 후 오류 대응 — 최신 검증

배포 ZIP의 기존 DB와 시연 DB는 현재 Linux 환경에서 로그인 이후 탐색·마이페이지·상세·알림 응답이 정상입니다. 사용자의 실제 Traceback은 아직 전달받지 않아 개별 환경의 정확한 원인은 확정하지 않았습니다.

확인한 실패 경로: 시스템 시간대 DB가 없을 때 Asia/Seoul 조회 실패, 모집 날짜가 NULL일 때 문자열 비교 TypeError, Windows 기본 CP949 인코딩으로 초기화 SQL을 읽을 때 디코딩 실패. 현재 한국 시각의 UTC+09:00 계산, 미완성 모집 정보 처리, 명시적 UTF-8 읽기로 보완했습니다.

시간대 DB 없음·초기화 인코딩·빈 모집 날짜·잘못된 모집 값 회귀 검증을 추가하여 **35개 실행 / 35개 통과**했습니다. Chromium D01–D12 기능 검사도 별도 임시 프로젝트에서 통과했습니다. 사용자 환경의 동일 증상 해결 여부는 실제 로그와 재실행 결과로 확인해야 합니다.

공식 다운로드 버튼 및 원문 파일을 제거하고 안내 화면에서 이메일·전화번호·담당자 성명을 제거했습니다. 삭제한 원문 경로는 404입니다. 기존 DB·사용자 첨부는 보존합니다.

최신 검증: 자동 테스트 42개 통과, Chromium D01–D12 검증 및 자유 파일명 PDF 저장·소유자 다운로드·익명 차단·교수 확인 통과. 실행용 ZIP의 기존 시연 DB와 DB 없는 새 환경 모두 python app.py 실행, 학생·교수 로그인과 주요 화면 정상 응답을 확인했습니다.

제출 화면 정리: 공통 제목의 D01–D12/프로젝트 표기, 화면의 테스트용·과제용·샘플 문구를 제거했습니다. 로그인과 등록 안내는 서비스 사용 안내로 교체했습니다. 자동 테스트 42개와 Chromium 전체 흐름 검증을 통과했으며 각 캡처 화면의 본문에 개발용 문구와 화면 번호가 없는지 확인했습니다. 실행용 ZIP은 최신 템플릿을 포함하고 기존 DB·첨부 파일은 그대로 보존합니다.
