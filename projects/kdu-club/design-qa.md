## 확인 내용

- Typography: 한국어 산세리프, 제목·본문·설명 계층, 폼 레이블·오류 문구를 반영. Noto Sans CJK KR 계열을 사용하며 Figma 원본 글꼴은 확인되지 않음.
- Layout: 밝은 회색 바탕, 흰색 상단 메뉴·둥근 카드, 3열 동아리·통계, 상세 2열, 운영 좌측 메뉴와 신청 목록/상세 구성을 확인함.
- Colors: 파란 액션·선택 상태, 옅은 파랑 안내, 초록 승인, 주황 대기, 빨강 반려·오류를 반영함.
- Assets: Lucide 1.55.0의 실제 SVG 아이콘을 자체 호스팅하고 라이선스를 포함함. 화면에 별도 사진 자산이 없어 새로운 래스터 이미지는 생성하지 않음.
- Copy: literal `\\n`은 실제 줄바꿈으로 정리함. 지원하지 않는 공식 학교 인증을 암시하지 않음. 상태·날짜·인원·첨부 크기는 실제 데이터로 표시함.
