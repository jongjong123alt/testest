# AI 초안 기준과 출처

이번 제출의 AI 초안은 사용자가 지정한 UI 최초 적용 버전입니다. Git 2fdda11의 projects/kdu-club 소스를 실제 Git 객체에서 추출했습니다. 파일을 현재 코드로 재구성하지 않았습니다. 각 파일의 SHA-256은 evidence/ui_draft_hashes.json에 있습니다.

이 버전은 AI가 이 대화에서 만든 데스크톱 UI 및 기능 구현본입니다. 업로드 이전의 최초 AI 생성물이나 모든 개발의 최초 버전이라는 뜻은 아닙니다. UI 적용 이전의 최초 프롬프트는 확인되지 않았지만 이번 제출 초안 기준은 확정되었습니다.

DB·캐시·개인 첨부는 제외했습니다. 해당 버전은 당시 실행 방법을 따릅니다. 새 환경의 실행 방법과 검증은 최종본 03_source_code를 사용하세요. 초안 버전의 실행을 이번 검증에서 통과시켰다고 주장하지 않습니다.

학생 직접 수정 기록은 실제 수행 사실을 확인해야 합니다. AI가 만든 기능을 학생 직접 작성으로 표시하지 않습니다. 학생이 수행할 수 있는 수정·검증 후보는 06 폴더의 student_review_tasks.md에 별도로 제공합니다.
