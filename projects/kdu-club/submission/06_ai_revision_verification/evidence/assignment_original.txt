                                      [소프트웨어개발 2회차]

                        학생 발굴 캠퍼스 문제 해결 웹서비스 개발


1. 목표
1회차에서 익힌 설계 방법론(요구사항 정의 → 플로우차트 → 기능 분해 → 구현 → 검증)과 AI 코드 검
증 습관을, 이번에는 본인이 직접 발굴한 캠퍼스 문제에 스스로 적용합니다. 이번엔 정해진 미션이 없
으므로, 문제를 찾고 정의하는 것부터 여러분의 몫입니다.



2. 주제 선정

2.1 카테고리
'캠퍼스 생활 편의·효율화' 안에서 자유롭게 고릅니다. 예를 들면 학식 혼잡도 확인, 강의실·동아리방 예
약, 도서관 좌석 현황, 분실물 찾기, 스터디 모임 매칭 같은 것들이 있습니다. 이건 예시일 뿐이니, 본인
이 캠퍼스에서 직접 겪은 다른 불편함이어도 좋습니다.


2.2 아이디어 승인 (필수)
2회차는 1회차를 마친 순서대로 개인별로 시작합니다. 본인이 2회차를 시작하려는 시점에, 아래 내용
을 정리해 카카오워크 1:1 채팅으로 먼저 보내 교수 승인을 받은 뒤 구현을 시작하세요.

  • 어떤 문제를 해결하려는가

  • 누구를 위한 서비스인가

  • 핵심 기능은 무엇인가 (3~4 줄 정도로 충분)

승인 전에는 구현에 들어가지 마세요. 설계(플로우차트 구상 등)는 승인을 기다리는 동안 미리 해도 됩
니다.



3. 기술스택 (1 회차와 동일 유지)
Backend: Python Flask   /   Database: SQLite   /   View: Jinja2 템플릿

새로운 도구를 배우는 데 시간을 쓰지 않고, 이미 익숙한 도구로 문제 해결 자체에 집중하세요.



4. 필수 추가 기능 (아래 중 최소 1 개 포함)
1회차에는 없던 요구사항입니다. 본인의 주제에 자연스럽게 어울리는 것으로 하나 이상 골라 넣으세요.


4.1 외부 API 연동
다른 서비스가 이미 가진 데이터나 기능을 내 앱에서 가져다 쓰는 것입니다. 예를 들어 기상청 공공데
이터 API로 날씨를 가져와 '비 오는 날은 000 추천' 같은 로직을 넣을 수 있고, 셔틀버스 예약에 공공데
이터포털의 교통 API를 붙일 수 있습니다. 파이썬의 requests 라이브러리로 외부 주소에 요청을 보내고
응답(JSON)을 받아 화면에 표시하는 방식입니다. API가 키를 요구한다면, 코드에 직접 적지 말고 .env
파일에 보관하고 .gitignore로 관리하세요 (3회차에서 이렇게 해야합니다. ).


4.2 파일 업로드
사용자가 이미지나 문서 같은 파일을 직접 올리고, 서버가 저장한 뒤 데이터베이스에는 파일 경로만 기
록하는 기능입니다. 분실물 찾기라면 분실물 사진 첨부가 대표적입니다. Flask에서는 request.files로 파
일을 받고 secure_filename()으로 파일명을 안전하게 처리한 뒤 서버의 uploads 폴더 등에 저장합니다.
반드시 허용할 파일 확장자와 최대 용량을 제한하세요 — AI 초안 코드가 이 제한을 빠뜨리는 경우가
많으니, 검증 기록에서 꼭 확인할 항목입니다.


4.3 검색·필터
목록으로 보여지는 데이터를 조건에 맞게 좁혀 보는 기능입니다. 도서관 좌석이라면 '콘센트 있는 자리
만', 분실물이라면 '지갑만 검색' 같은 것이 해당합니다. 사용자가 입력한 조건으로 SQL의 WHERE 절을
만드는데, 조건을 문자열로 직접 이어붙이면 SQL 인젝션 취약점이 생길 수 있습니다. 반드시 파라미터
바인딩(? 플레이스홀더)을 쓰는지 확인하세요.

<예>

query = "SELECT * FROM items WHERE name LIKE ?"
cursor.execute(query, (f"%{keyword}%",))

4.4 알림
특정 상황이 생겼을 때 사용자에게 능동적으로 알려주는 기능입니다. 가장 권장하는 형태는 앱 안에 '
알림함' 테이블을 만들어, 이벤트가 생기면 기록을 남기고 다음 접속 시 화면에 보여주는 '인앱 알림'입
니다. 이메일이나 카카오톡 알림톡처럼 외부로 실제 발송하는 방식은 별도 설정과 가입이 필요해 부담
이 클 수 있으니, 여력이 되는 경우에만 도전하세요.



5. AI 도구
1회차와 마찬가지로 본인이 이미 계정을 가진 AI 코딩보조 도구(클로드, 챗GPT 등 무엇이든)를 자유롭
게 사용합니다.

7. 선택한 기능별 검증 체크리스트
4장에서 고른 기능에 해당하는 항목을 검증 기록에 반드시 포함하세요.

 • 외부 API 연동 — API 요청이 실패했을 때(응답 없음, 오류) 화면이 깨지지 않고 적절히
  처리되는가? API 키가 코드나 GitHub 에 노출되지 않았는가?

 • 파일 업로드 — 허용하지 않은 확장자나 지나치게 큰 파일을 올리면 거부되는가?

  않는가?
