## 실행
Python 3.10 이상(3.12 권장)을 설치한 PC에서 ZIP 전체를 쓰기 가능한 폴더에 풀고 `python app.py`를 실행합니다. Windows에서 명령을 찾을 수 없다면 `py app.py`를 사용합니다. 최초 라이브러리 설치에는 인터넷 연결이 필요합니다. Python 자체를 자동 설치하거나 인터넷 없이 새 PC에 설치하는 기능은 아닙니다.

## 코드 변경
- app.py 맨 앞: 외부 모듈 import 전에 직접 실행일 때만 bootstrap.ensure_dependencies()를 호출합니다. Flask CLI/테스트 import에는 자동 설치하지 않습니다.
- bootstrap.py: requirements.txt 버전과 실제 import를 확인합니다. 준비되어 있으면 즉시 앱을 실행합니다.
- 필요 시 프로젝트 .venv를 생성/재사용하고, 해당 Python의 `-m pip`로 고정 의존성을 설치합니다. pip가 없으면 ensurepip를 시도합니다. 전역 Python 라이브러리는 변경하지 않습니다.
- 설치 후 상태를 다시 확인하고 같은 --original/--host/--port 인자로 앱을 재실행합니다. 설치 실패 시 오류와 재시도 안내를 출력하고 서버를 시작하지 않습니다.
- tests/test_bootstrap.py: 환경 재사용, 실패 중단, pip 준비, 인자 전달, 불완전한 배포 등의 7개 테스트를 추가했습니다.
- 03/04 소스 ZIP과 실행 ZIP에 app.py·bootstrap.py를 반영했습니다. 기존 실행 ZIP의 DB·첨부 바이트는 보존했습니다. 01 전체 순서도의 시작 구간도 수정했습니다. 기존 보고서/PPT의 개요도는 당시 흐름이며, 현재 전체 흐름은 01_flowchart의 파일을 확인하세요.
